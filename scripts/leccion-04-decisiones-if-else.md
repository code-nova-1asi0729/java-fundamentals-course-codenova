# Guion – Lección 4: Decisiones con if-else

**Duración:** 7 min
**Editor:** OnlineGDB (lenguaje: Java)
**Video:** PENDIENTE-VIDEO-L4
**Práctica:** PENDIENTE-ONLINEGDB-L4
**Archivos:** `/starter-files/leccion-04-decisiones-if-else` → `/completed-examples/leccion-04-decisiones-if-else`

**Objetivo:** al terminar, el estudiante hace que el programa decida qué hacer según una condición.

**Contenido que debe cubrir:**
- Analogía: si llueve, llevo paraguas; si no, llevo gorra.
- `if`, `else if` y `else`; paréntesis para la condición y llaves para el bloque.
- Usar las comparaciones y `&&` de la lección 3 dentro del `if`.
- Ejemplo del héroe: game over, poca vida o en plena forma; comprar una poción.
- Error típico: poner `;` después del `if (…)` o usar `=` en lugar de `==`.
