# Guion – Lección 6: Métodos, parámetros y entrada con Scanner

**Duración:** 8 min
**Editor:** OnlineGDB (lenguaje: Java)
**Video:** PENDIENTE-VIDEO-L6
**Práctica:** PENDIENTE-ONLINEGDB-L6
**Archivos:** `/starter-files/leccion-06-metodos-y-scanner` → `/completed-examples/leccion-06-metodos-y-scanner`

**Objetivo:** al terminar, el estudiante crea métodos con parámetros y `return`, y lee datos del teclado con `Scanner`.

**Contenido que debe cubrir:**
- Método = una receta con nombre que se puede usar muchas veces.
- `static void` (solo hace algo) y `static int` con `return` (devuelve un resultado).
- Parámetros: los datos que recibe el método.
- `Scanner`: `import java.util.Scanner;`, `nextLine()` para textos y `nextInt()` para números.
- Cómo escribir en la consola de OnlineGDB cuando el programa pide datos.
